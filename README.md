## Miniquad (a fork)

This repository contains a fork of miniquad, a graphics library.
The goal of this fork is to turn miniquad into a slightly more typesafe API,
that is well-integrated into Rust's existing ecosystem, while preserving
the original API design.

The library targets Desktop (OpenGL 3.3) and WASM (WebGL 2).
